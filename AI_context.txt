1. WHAT IS TMO?
================================================================================

TMO (Temporal Multi‑Omics) is a deep‑learning framework that learns signed,
cell‑state‑conditional regulatory lags (Δτ) between chromatin accessibility
(ATAC) and gene expression (RNA) from single‑cell multi‑omic data.

The core innovation is an asymmetric cross‑modal attention mechanism:
- A first pass of a transformer encoder produces a cell embedding from ATAC
  tokens only.
- A LagMLP predicts per‑component regulatory lags and window widths.
- A second pass biases cross‑attention so that ATAC tokens attend to RNA tokens
  shifted by the predicted time offset.

Biological interpretation (after uniform sign convention):
  Positive Δτ = ATAC leads RNA (chromatin priming)
  Negative Δτ = RNA leads ATAC (activity‑dependent regulation)

The method is validated on four 10x Multiome datasets:
  - Mouse brain (Pax6 root marker)
  - Human brain (ASCL1 root marker)
  - Mouse kidney (Pax2 root marker)
  - Human PBMC (CD34 root marker)

3. FINAL PIPELINE (how to run TMO step by step)
================================================================================

All scripts are run from the `scripts/` folder with `tmo_env` conda environment.

3.1. Preprocessing
    python 1_create_gene_level_tmo_data.py --data_dir <folder> 
        --output_file <file.h5ad> --root_marker <gene>

3.2. Component annotation (requires internet)
    python 2_annotate_components.py --data_path <file.h5ad> 
        --n_components 50 --organism <human|mouse>

3.3. Train asymmetric model (on full dataset)
    python 3_train_tmo_asymmetric.py --data_path <file.h5ad> 
        --epochs 50 --val_interval 5 --lambda_lag 0.1

3.4. Train symmetric baseline (no attention bias, no lag loss)
    python 3_train_tmo_asymmetric.py --data_path <file.h5ad> 
        --epochs 50 --val_interval 5 --lambda_lag 0.1 --symmetric

3.5. Evaluation and figures
    python 4_evaluate_asymmetric.py ...    # Δτ heatmap (Figure 1)
    python 5_plot_correlation_heatmap.py ...  # U‑shape (Figure 2)
    python 6_plot_training_curves.py ...      # Training curves (Figure 3)
    python 7_lcs_analysis.py ...              # LCS scatter/bar comparison
    python 8_plot_marker_delta_tau_profiles.py ...  # Marker profiles
    python 9_gene_program_ordering.py ...     # GO enrichment bar plot

3.6. Independent validation
    python 11_chipseq_validation.py ...   # ChIP‑seq (two‑sided Mann‑Whitney)

3.7. tmopy (Python API) equivalent
    import tmopy as tmo
    adata = tmo.pp.read_10x_multiome(...)
    adata = tmo.pp.compute_gene_level_atac(adata)
    adata = tmo.pp.compute_pseudotime(adata, root_marker="Pax6")
    tmo.tl.annotate_components(adata, organism='mouse')
    model = tmo.tl.train_asymmetric(adata, epochs=50, save_model="best.pt")
    delta_tau, pt_grid, lcs, labels = tmo.tl.evaluate_asymmetric(
        adata, "best.pt", cluster_aggregate=True)
    tmo.pl.plot_delta_tau(delta_tau, pt_grid, labels, save="fig1.pdf")

5. TECHNICAL DETAILS (for reproducibility)
================================================================================

Model architecture:
  - d_model = 64, n_heads = 4, n_layers = 2, n_comps = 50 per modality
  - Tokenizer: proj(latent_value) + modality_embedding + pseudotime_embedding
  - LagMLP: LayerNorm first, then Linear→GELU→Dropout→Linear→GELU→Dropout→Linear→Tanh
  - WidthMLP: same, output via Softplus + σ²_min = 0.001
  - Two‑pass forward: first pass (no bias) → cell embedding → predict lags →
    second pass (with Gaussian attention bias)
  - Loss: L_total = λ_recon * MSE_recon + λ_lag * MSE_lag
  - λ_recon = 1.0, λ_lag = 0.1
  - Optimiser: Adam (lr=1e-3), StepLR (step=20, gamma=0.5), 50 epochs

CCF target:
  - Sliding window (half‑width 0.1), 9 centres (0.1 to 0.9)
  - Interpolation onto regular grid (200 points) for accurate lag estimation
  - Gaussian process smoothing (Matern‑3/2 kernel)
  - Target: smoothed lag at last pseudotime window (τ=0.9)

Pseudotime:
  - First diffusion component from RNA, min‑max scaled to [0,1]
  - Optional reversal with early marker (e.g., Pax6, CD34)
  - Reversal flag stored in .uns['pseudotime_reversed']
